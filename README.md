# 🚖 Gestión Pago Taxi | Plataforma para Conductores y Propietarios

Aplicativo web desarrollado para la administración y control de pagos diarios entre conductores y propietarios de taxis.

## ✨ Características principales

👤 **Roles Inteligentes**

* 🔑 Rol **Propietario**
* 🚕 Rol **Conductor**

## 🚗 Funcionalidades del Propietario

* Registro y administración de vehículos
* Generación de tokens únicos para vincular conductores
* Visualización del estado de pagos por vehículo
* Dashboard administrativo en tiempo real

## 👨‍✈️ Funcionalidades del Conductor

* Registro mediante token generado por el propietario
* Asociación automática al calendario del vehículo
* Registro de pagos diarios directamente desde la plataforma
* Seguimiento visual del estado de pagos

## 📅 Calendario Inteligente de Pagos

* 🟢 Día pagado = color verde
* 🔴 Día pendiente = color rojo
* Control visual rápido y eficiente

## 📢 Dashboard Comunitario

Los usuarios pueden realizar publicaciones en tiempo real sobre:

* 🚨 Retenes
* ⚠️ Accidentes
* 🚧 Novedades en ruta
* 📍 Alertas para conductores

## 🛠️ Tecnologías Utilizadas

* ⚛️ React
* 🚀 Node.js / Express
* 🗄️ SQL
* 🎨 Diseño responsivo y moderno

## 🎯 Objetivo

Digitalizar y optimizar el control operativo y financiero entre propietarios y conductores de taxis mediante una plataforma intuitiva, visual y eficiente.

🔥 Sistema pensado para mejorar el control diario, reducir errores manuales y facilitar la comunicación entre conductores y propietarios.
